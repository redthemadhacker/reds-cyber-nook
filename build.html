Irezumi- Team Project

Collaborative full‑stack tattoo networking app built with React, Bootstrap, MongoDB, and Cloudinary. Our team engineered all frontend components, backend logic, authentication flows, and media handling, while integrating an existing API for artist data and location‑based discovery.
